One-click root

Pick Full root. Get a verified badge.

Jidr does the patching you would otherwise do by hand, then checks that su really works before it says Rooted.

Download Magisk 30.7step 1
Patch the boot image, keep the originalstep 2
Reboot (about 40 s)step 3
Install the Magisk appstep 4
Verify su -c idstep 5
Rooted · Magisk 30.7 verified 14:02 · uid=0(root)

If a step fails you see which one and why, with the log, and one click puts the device back the way it was.

Rooted emulators can't pass Play Integrity. Jidr says so wherever it matters.

MCP server

Let an agent drive. Watch it work.

Add Jidr to Claude or any MCP client and the agent can see and operate a device while you watch the device window. The device shows Busy · in use by agent.

screenshotPNG of the screen
tapx, y in device pixels
typetext into the focused field
ui_treethe current view hierarchy
logcatfiltered lines, streamed
