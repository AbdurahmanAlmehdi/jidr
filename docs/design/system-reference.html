One rule, no exceptions

Join the path with -. CSS prefixes --jidr-. Slint drops a leading color- and lives in export global Theme. A clash fails the generator.

Modes

Dark is the primary mode: $value is dark, $extensions["ly.jidr"].modes.light is light. Slint resolves with dark ? a : b from Palette.color-scheme; CSS uses prefers-color-scheme, data-theme on <html>, or .jidr-light / .jidr-dark on any element.

Aliases stay aliases

{status.positive.container} becomes var(--jidr-status-positive-container) in CSS and a property reference in Slint, so changing a shared pair changes every status that uses it.

Only components read tokens

No raw hex in a component, ever. Status colour always comes in through a status.<kind>.<state> token, never through positive or root directly.

Root states without colour

  • Verified: the only solid plate in the product, badge-check icon, “Rooted · Magisk 30.7”.
  • Full root / Setting up / Unverified: outlined pill; key, spinner, question-mark icons and different words.
  • Failed: 2 px heavy outline, circle-x icon, reason follows the label.
  • Shell root: neutral filled pill with the terminal prompt glyph.
  • Not rooted: no container at all, minus glyph, secondary text.
  • Beta: never alone; a square uppercase tag with a flask after the root badge.

Dashed outlines from the Workbench sketch are dropped: Slint has no dash pattern for borders, and a shape we cannot build is not a shape.

Device status is always visible

Rows, cards, tabs and the device window title all show the pill. Booting carries its percentage, Running its uptime, Busy says who holds the device (CLI or agent). Crashed is the only red device state.

Starting, Booting and Stopping share the transition pair and the spinner: the user does the same thing for all three (wait). Stopped and Paused share neutral; the icon tells them apart.

Arabic needs more room

Arabic line heights run 1.6–1.75× the size against Latin's 1.2–1.4×. Kufi has tall ascenders (alef, lam) and deep descenders (ya, ra), and diacritics stack above and below them. At Latin line heights they collide with the line above.

At text sizes (11–15 px) Arabic goes up 1 px; Kufi's small counters read smaller than Geist at the same size. At 19 px and up it comes down 1–6 px, because the Arabic headline would otherwise outweigh the Latin one.

No tracking in Arabic

Letter-spacing is 0 for every Arabic role: spacing breaks the joins between letters. Uppercase and tracked labels have no Arabic equivalent; use weight instead.

Rows keep their height

Row heights come from density tokens, not line height, so a device row is 52 px in both scripts. Arabic text sits in the same box with its own line height. Two-line rows in Arabic may need the compact density's single line.

Tabular figures

Slint cannot switch OpenType features, so live numbers use Geist Mono, whose figures are tabular by construction. The site uses the same face, so type.metric looks the same in both products. Numbers stay Western digits (0–9) in Arabic, as Libyan software does.

Slint: Rust reads NSWorkspace.accessibilityDisplayShouldReduceMotion and sets Theme.reduce-motion; every motion-*-duration switches to its reduced value. Site: tokens.css swaps the same durations under prefers-reduced-motion: reduce, and keyframe animations (spinner, shimmer) are removed.

When motion is allowed

  • To show where something came from (sheet, popover, panel).
  • To show that a state changed (status, root success).
  • To show that work is happening (progress, spinner, skeleton).
  • Never for decoration, page-load sequences or scrolling effects.

Create-device sheet

Single form, not a stepper. Every field has a sensible default, so the common path is name → ⌘↵. Users are technical and keep the app open all day; a stepper would put four clicks between them and a device and hide the one choice that matters (root mode) on step three. The form keeps root mode visible, folds rarely-touched hardware into Advanced, and validates inline. First-run uses the same sheet with the downloaded image preselected.

Guidelines

Rules

Accent and hero budget

One hero per surface

Each surface has exactly one thing it is for, set in type.hero or type.web.hero: the Android screen in the device window, the device name in its detail view, the root result in the root flow, the headline on the landing page.

One accent action per surface

At most one accent-filled control per surface (a window pane, a sheet, a landing section): the primary button, or a selected segment, not both. Everything else is secondary or tertiary. The device card's Start counts as its card's one; a grid of cards is fine because each card is its own surface.

Root violet is not an accent

Violet only ever means root. It never colours a button, link, selection or chart. The only solid root plate is the verified badge.

Status colour is information

Status pairs don't count against the accent budget, but they are never decorative: no coloured headers, no tinted cards to make a section pop.

Icons

Lucide, outlined

All icons are Lucide (ISC licence; attribution in About › Licenses and the site footer: “Icons by Lucide, ISC licence”). Stroke 1.75 at every size, round caps. Shipped as SVG files in icons/ and loaded in Slint with @image-url, tinted with colorize.

Filled is a state, not a style

Outlined by default. Filled is reserved for: the Running dot, the record button while recording, the toggle thumb. No filled variant of any other icon, so filled always reads as “on right now”.

Sizes

14 inside pills, badges, small buttons, menus; 16 in buttons, sidebar, inputs; 20 in the device toolbar and empty states. Device toolbar buttons are 32 px targets with 17 px glyphs.

Mirroring rules

Mirror icons that point along the reading direction: arrows, back/forward, chevrons, undo/redo, skip, progress and list indent. Never mirror icons that show a real-world object or a clockwise convention: checks, play/pause/record, rotation (device rotate left/right keep their physical meaning), clocks, search, terminal, keys, volume.

Framing the device screen

Fit (default)

The screen and its bezel scale to the largest size that fits the stage, keeping the device's aspect ratio. Scale is continuous, never rounded to 50% steps. The screen never shrinks below window.device.min-screen-height (360 pt); the window can't be made smaller than that plus the toolbar.

Pixel-perfect 1:1 (⌘0)

One device pixel per physical display pixel: on a 2× Retina display a 1080×2400 screen is 540×1200 pt. If that is bigger than the stage, the stage scrolls; the screen is never cropped or scaled. The toolbar button stays highlighted while 1:1 is on.

Letterbox

All stage space around the bezel is color.surface.sunken: #0A0C0F in dark, #E9ECF0 in light. Nothing is drawn on it: no shadows behind the device, no reflections, no gradients. Minimum gap bezel-to-edge is frame.stage-padding (24 pt).

Rotation and panels

Rotating swaps the frame's width and height and re-fits; the window does not resize on its own. Opening the widget panel narrows the stage and re-fits the screen; the panel never overlaps it.

Copy rules for honest states

Say what happens

Name the action and its cost: what changes, how long, how much disk. Buttons are verbs that match the result (Delete device → toast “Deleted Tablet 11”).

State limits plainly

Wherever root, Play Store images or agents are involved, say the limit where the user decides, not in a help page: Play Integrity on the Full root card and in the device inspector; “an agent is driving this device” before Stop.

Honest progress

Progress shows real bytes or real steps. If a step's length is unknown, show the step name and a spinner, never a fake bar. Verified means Jidr ran su -c id and got uid 0; until then the badge says Full root or Root unverified.

Tone

Confident, technical, warm. Short labels, sentence case, no exclamation marks, no emoji, no “Oops”. Errors say what went wrong and what to do next, and that the user's data is safe when it is.

Shipped alongside this page.

tokens.jsonW3C Design Tokens Format 2025.10. The only file anyone edits. Colour values are objects ({colorSpace, components, hex}); light values and Reduce Motion values live in $extensions["ly.jidr"].
generate.pypython3 generate.py tokens.json out/ → tokens.css, theme.slint, contrast.json. Fails on a Slint name clash; prints failing contrast pairs.
theme.slintexport global Theme { … } with every token, plus export global StatusMeta { … } with each status's icon (@image-url) and label (@tr). Compiled with Slint 1.x.
tokens.css--jidr-* custom properties. Dark on :root, light via prefers-color-scheme, data-theme, or .jidr-light / .jidr-dark; Reduce Motion overrides included.
icons/The Lucide SVGs StatusMeta references, with Lucide's ISC licence.
