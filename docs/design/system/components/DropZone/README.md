# DropZone

Drop target for GPX/KML routes and APKs.

- Default `jidr-color-border-strong` 1.5 px on `jidr-color-surface-sunken`; drag-over turns `jidr-color-accent-fill` on `jidr-color-accent-container`.
- Error names the file type it got and what it accepts. Installing shows real progress.
- APKs can be dropped anywhere on the device window; the whole stage becomes the target.
