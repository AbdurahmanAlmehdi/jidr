Let an agent drive. Watch it work.

Jidr runs an MCP server. Add it to Claude or any MCP client and the agent can see and operate a device while you watch the device window. The device shows Busy · in use by agent.

  • screenshot PNG of the screen
  • tap x, y in device pixels
  • type text into the focused field
  • ui_tree the current view hierarchy
  • logcat filtered lines, streamed
claude_desktop_config.json
{
  "mcpServers": {
    "jidr": {
      "command": "jidr",
      "args": ["mcp"]
    }
  }
}
