# NumericField

Number input with its unit inside the field: latitude, longitude, altitude, accuracy, RAM, cores.

- Value in Geist Mono with tabular figures; unit in `jidr-color-text-tertiary`.
- Coordinates: signed decimal degrees, 4 decimals shown, 6 accepted. Values stay LTR in Arabic.
- Errors state the valid range (−90 to 90).
