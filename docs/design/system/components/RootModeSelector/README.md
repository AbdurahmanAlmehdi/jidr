# RootModeSelector

Three radio cards: None, Shell root (adb), Full root. Each says what it does in one line.

**Consumer provides:** selected mode, image tag (Play Store ⇒ Beta and Shell disabled), API level.

- A radio group: ↑/↓ or 1/2/3 choose. Selected card: `jidr-color-accent-container` fill and `jidr-color-accent-fill` outline.
- Play Store images: Full root carries the Beta tag and, on the card itself, “Rooted emulators can't pass Play Integrity.”
- Default comes from Settings › Default root mode.
