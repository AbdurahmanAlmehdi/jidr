# DeviceFrame

The bezel around the Android screen, per device class.

- Bezel colour `jidr-color-surface-device-bezel` (dark in both themes, like hardware); sizes `jidr-frame-<class>-bezel`, `-radius`, `-screen-radius`.
- Plain rounded rectangle: no notch, camera, buttons or brand silhouette.
- Bezel stays the same size in window points as the screen scales; minimum gap to the window edge `jidr-frame-stage-padding`.
