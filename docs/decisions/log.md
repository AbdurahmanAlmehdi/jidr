# Decisions log

Product and architecture decisions made while building the MVP (October 2026). Code comments cite them as `D<n>`. Architecture decisions with more context are the ADRs in this folder (`0001-…`, `0002-…`).

To change a decision, open an issue that names it and explains why; the change lands as a new or amended row here, never as a silent edit elsewhere.

| # | Decision |
|---|---|
| D1 | Name **Jidr** (جذر, "root"). CLI `jidr`, crates `jidr-*`, app `Jidr.app`, GitHub org `jidr-dev`, site `jidr.ly`. |
| D2 | UI toolkit **Slint** (GPLv3 accepted); possible egui migration later. |
| D3 | Private SDK; Android Studio SDK/AVDs read-only. |
| D4 | Daemon auto-starts on first client, lives while devices run, exits 10 min after the last stops; no launchd agent. |
| D5 | MCP: read/interact/start/stop by default; destructive actions need `--allow-destructive` or an `agent-owned` device. |
| D6 | Play Store + Magisk: pursue full support first (D21), guided-tap beta only as fallback. |
| D7 | Default root mode: `adb` on images that allow it; Magisk one click away and highlighted. |
| D8 | Headless license consent via `--accept-licenses`, per license hash, re-prompt on change. |
| D9 | Dynamic ports (no cap; `adb connect` past ~16); no auto-restart on crash, logs auto-saved, offer cold boot/wipe; per-device single-writer lock. |
| D10 | Own CLI + exit codes, versioned `--json`; no gmtool-compat layer in the MVP. |
| D11 | 🔎 research features ship post-MVP as listed gaps. |
| D12 | Shared folders post-MVP. |
| D13 | Recording: MP4/H.264 via VideoToolbox from the frame stream; audio post-MVP. |
| D14 | GPS map: OpenStreetMap tiles, attribution, configurable URL; GPX/KML replay. |
| D15 | MVP = Apple Silicon macOS only; code stays portable. |
| D16 | Landing page: Astro + Vue islands on Cloudflare Pages. |
| D17 | No telemetry; no auto-updater (Homebrew cask + GitHub Releases check). |
| D18 | Split licensing: Apache-2.0 everywhere except `jidr-ui` + `apps/jidr-gui` (GPLv3). |
| D19 | Names/handles as in D1. |
| D20 | Phase 1 spike tests Slint only (`SharedPixelBuffer`, then wgpu import if needed); egui is the documented fallback. |
| D21 | Play Store root R&D order: ramdisk boot-script grant → uiautomator auto-tap → guided-tap beta. |
| D22 | Magisk devices: adb shell auto-granted; apps prompt; opt-in "auto-grant all" per device. |
| D23 | API 29–36 arm64 supported; 28 best-effort; 25–27 not offered. |
| D24 | Generic device profile names; SDK device definitions imported as-is. |
| D25 | No paid tier; GitHub Sponsors (Open Collective later). |
| D26 | Repo at `github.com/AbdurahmanAlmehdi/jidr`; moves to the `jidr-dev` org before launch. |
| D27 | Built in three parallel streams after the core platform: A core platform, B player and widgets, C root, release and site. |
| D28 | CI: Linux KVM runners (x86_64 images) for emulator tests on every PR; `cargo xtask e2e-mac` on an Apple Silicon Mac (arm64) before release. |
| D29 | Stop saves a quick-boot snapshot by default; cold boot is separate; root changes force a cold boot; root-tagged snapshots. |
| D30 | Magisk APK cache by SHA-256, `--magisk <path>` offline, `jidr cache prune`, per-device disk usage. |
| D31 | `jidr uninstall [--purge]` + "Remove all data…"; never touches the Studio SDK; removes Jidr MCP config entries. |
| D32 | Signing with the maintainer's Apple Developer ID; unsigned DMG with a CI warning until the signing secrets exist. |
| D33 | English-only MVP, all strings via `@tr`, RTL-checked; Arabic UI post-MVP; Arabic landing page at launch. |
| D34 | Pre-launch "coming soon" site without email capture; brand: a root growing into a phone outline, جذر + Latin wordmark. |
| D35 | Dropped `.zip`: Magisk module install + reboot on Full-root devices; otherwise pushed to `/sdcard/Download` with a note. No image flashing (R12). |
| D36 | Phase 8a adds fingerprint touch/remove (R8), mobile signal bars (R3) and host webcam camera (R7); all other custom-work findings are post-MVP. |
| D37 | Research findings accepted with their stated targets (post-MVP items are GitHub issues labelled `upcoming feature`); R10 Device Link rejected. MVP+ queue after the MVP: R5 build props (Magisk `resetprop`), R12 modules. R6 disk I/O moved to Post-MVP after the proof run (the emulator kernel has no block throttling). |
| D38 | Research proofs ran on a throwaway arm64 AVD. |
| D39 | Brand assets live in `assets/brand/` (regenerated by `assets/brand/build.sh` from the approved symbol). App icons in `apps/jidr-gui/assets/` (`Jidr.icns`, in-app `symbol.svg`, menu-bar template); web set in `assets/brand/web/`, copied into `site/public/`. |
| D40 | R15 WebRTC not needed: ADR-0001 passed with inline RGBA frames. Phase 9d adds `root.module.install` (D35). R5 becomes Phase 9f (MVP+). Repo made public (CI on standard runners is free). |
| D41 | Design adopted: direction **Workbench** (dark-first). Tokens in `docs/design/tokens.json` are the single source; Slint `theme.slint` is generated by `jidr-ui/build.rs` and the site's `tokens.css` by a site script. Fonts Geist / Geist Mono / Noto Kufi Arabic bundled (OFL). Lucide icons. Chosen concepts: launcher 1A (sidebar + detail), device window 4A (docked panel), landing 8A. Index: `docs/design/README.md`. The app icon keeps its approved gradient; the UI uses tokens only. |
